# Kimono - Ninja på uppdrag

Pixel art Japanese ninja game built with Grok.

## Features
- Choose between Levels (5 banor + boss) or Endless Runner
- Backgrounds change in Endless mode (sakura forest, mountain temple, night village, bamboo forest)
- Shuriken throwing, power-ups (heart, speed, shield), multiple enemies, boss fight
- Highscore saved locally
- High quality pixel art graphics

## How to play
Open `kimono.html` in a web browser (works on desktop and mobile).
- SPACE / left click / left touch = Jump
- X / right click / right touch = Throw shuriken

The full game file (`kimono.html`) is ~6MB due to embedded pixel art assets. It can be downloaded from the Grok chat and committed here if needed.

Built as a complete playable prototype.
